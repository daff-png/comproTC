# Teman Canggih — Company Profile

Website company profile berbasis Next.js, menggunakan palet brand `#0F172A`, `#2563EB`, `#06B6D4` dan font Poppins sesuai brand guide.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Build untuk hosting

```bash
npm run build
```

Next.js dikonfigurasi untuk static export. Hasil siap unggah ada di folder `out/`. Hosting dan domain dapat diatur sendiri tanpa layanan server Node.js.

## Konten

Copywriting mengikuti materi yang diberikan. Portofolio proyek tidak ditampilkan karena belum ada studi kasus atau hasil yang bisa diverifikasi. Logo website menggunakan gambar asli yang diberikan (`public/brand-logo-original.png`).
